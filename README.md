# 🏥 Foreign Patient Group Management Backend

이 프로젝트는 삼성 서울 병원 및 다양한 기관에서 외국인 환자 데이터를 효율적으로 수집·관리할 수 있는 **외국인 환자 그룹 배정 관리 시스템**의 백엔드입니다. 
사용자는 소속 기관에 따라 역할 기반으로 데이터를 조회·추가할 수 있으며, 관리자(ADMIN)는 전체 데이터를 조회, 수정, 엑셀 파일로 다운로드할 수 있습니다.

> ✅ 이 백엔드 서비스는 **Render**를 통해 배포되어 실제 운영 환경에서 사용 가능합니다.

---

## 🔧 기술 스택

| 기술 | 설명 |
|------|------|
| **Node.js** | JavaScript 런타임 환경으로 서버를 구성 |
| **Express** | 경량 웹 프레임워크, RESTful API 구축에 적합 |
| **Prisma** | 타입 안정성과 편리한 ORM 제공 |
| **PostgreSQL** | 안정적이고 확장 가능한 RDBMS |
| **Docker** | 컨테이너화된 환경을 통해 배포 및 실행 안정성 확보 |
